# Doceria Gourmet IANES 🍭🍬

# Autor: Isabelle dos Santos de Abreu, Turma: DS3B

Sistema para gerenciamento de doces, controle de estoque e registro de descartes.

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL
- Knex

## Funcionalidades

- Login
- Cadastro de doces
- Listagem de doces
- Controle de estoque
- Registro de descartes
- Pesquisa e ordenação

## Como executar

1. Execute o script_banco.sql
2. Configure o banco no knexfile.js
3. Execute:

npm install

4. Inicie a API:

node app.js

5. Abra o frontend
